  1. Download the ChatGPT plugin from Host Terminal releases and extract it. Install Node.js 22 or newer on this computer.

Setup & shortcuts
Connect a desktop computer
  1. Load the package's extension folder from Chrome's Extensions → Developer mode → Load unpacked.
  2. Install the native companion from the package:
    Use host-terminal.exe on Windows. The installer registers this extension ID for your user account.
  3. Return here and choose Connect to this computer. If Chrome was open during installation, reconnect or restart Chrome.
The native companion runs shells with your current OS account's permissions. This extension does not provide a terminal inside Android or iOS Chrome.

Session lifetime
Closing this page detaches its views. The companion keeps sessions alive while Chrome and its native connection remain open. Reopen this page to attach again. A session can be attached to one page at a time.
Reattachment replays a bounded recent output stream. It is not an exact terminal screen checkpoint. For durable jobs or exact full-screen reattachment, run tmux or screen inside the shell. End all sessions terminates the companion's sessions.
Connection troubleshooting
Run host-terminal doctor --extension-id YOUR_ID using this page's extension ID. Check that the installed companion and Native Messaging manifest still exist. After moving the native executable or changing your extension ID, run install again.
Chrome connects through Native Messaging. Optional ChatGPT access opens a private, authenticated loopback connection while enabled. Ordinary web pages have no command API.
